## Product Listing Best Practices

### Image Order (Every Listing)
1. **Hero** — Product name + edition + promise
2. **System** — "9 screens, not 29 tabs" / "4 nights, not 7" / "Snowball vs Avalanche"
3. **Details** — Cell language / ingredient notes / debt breakdown
4. **Screenshot** — Real usage example
5. **Formats** — Platforms + currency support

### Listing Copy Structure
1. Problem statement (1 sentence)
2. Solution promise (1 sentence)
3. What you get (bulleted)
4. Both formats included (Excel + Notion)
5. Customization options (currency, dates)
6. Edition call-out (Calm vs Loud contrast)
7. CTA: "Instant download, free updates"

### Tags Strategy (from SEO-AND-MARKETING.md)
- Core tags: adhd planner, budget spreadsheet, notion budget
- Edition-specific: minimalist planner (Calm) or dopamine planner (Loud)
- Product-specific: meal planner, debt payoff, etc.
