# Het Ritme Brand Exports — Etsy-Ready

All exports are sized for Etsy shop requirements.

## Size reference

| Export type | Dimensions | Use case |
|---|---|---|
| **Square marks** | 400×400 px | Shop icon, profile avatar, product badge |
| **Horizontal lockups** | 600×300 px | Shop banner, header graphic, social media |
| **Stacked lockups** | 400×500 px | Product cover, thumbnail, vertical layout |
| **Favicon** | 200×200 px | Browser tab icon |

## How to export as PNG

1. **Open `ETSY-EXPORTS.html` in your browser** (from this directory)
2. **Right-click any image** and select "Save image as..."
3. **Keep the filename as-is** (it includes dimensions)
4. **Choose PNG format** when prompted

All images export at exactly the dimensions needed—no resizing required.

## Editions

All exports are available in **four versions each**:

- **Calm** (sage #4A6250) — Low-stimulation, professional tone
- **Loud** (coral #D65A34) — Celebration-driven, energetic tone
- **Ink** (black #262119) — High-contrast, print-ready
- **Reversed** (white on dark) — For dark backgrounds

## Tips

- **Etsy shop icon**: Use `mark-calm-400x400.png` or `mark-loud-400x400.png`
- **Shop banner**: Use `lockup-h-calm-600x300.png` or horizontal lockup variant
- **Product thumbnail**: Use `lockup-s-calm-400x500.png` (stacked)
- **Print materials**: Use `mark-ink-400x400.png` (always works in B&W)
