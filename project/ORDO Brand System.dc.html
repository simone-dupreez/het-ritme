Turn 1 · dual-aesthetic brand system

One brand, two nervous systems.

Artboards 1a through 1g: name candidates, logo lockups, both design systems, the same Minimalist Budget rendered twice, shop assets, and the spec sheet. Structure borrows the conventions your reference template trained buyers on — left-rail tab menu, grey = automatic, white = yours, asterisk = required. Reference any id in chat and I’ll iterate.

Identical bones

Same rail, same three summary numbers, same five table columns, same card order. A buyer who switches aesthetic never relearns the tool.

What actually changes

Corner radius, fill vs. rule, colour count, bar weight, and voice. Nothing structural. That is what makes 24 SKUs maintainable by one person.

The app feeling

One question per screen, answer above the fold, detail below. The rail is numbered 1–2–3 so there is always an obvious next tap — no 29 undifferentiated tabs.

Only one instruction

White = you type, grey = works itself out, asterisk = needed for the maths. The legend sits in the rail on every tab, so no one has to remember it.

1G Navigation system + onboarding spec
29 tabs → 9 screens

Your reference workbook has 29 tabs, twelve of them identical months. Same logic, regrouped into three phases and nine named screens, with the twelve month tabs collapsed behind one month switcher. That is the whole difference between a spreadsheet and something app-shaped.

How it survives each platform

The system is defined once and degraded deliberately — never redesigned per platform.

Excel / Sheets
  • Rail = frozen column A of named links
  • Progress bars = data bars, single colour
  • Badges = static images, revealed by conditional format
  • Montserrat swapped for the closest installed sans
Notion
  • Rail = sidebar of nine sub-pages, numbered
  • Cell states = locked vs. editable properties
  • Celebration = callout block + emoji-free badge image
  • Colour maps to Notion’s nearest tint, not custom hex
