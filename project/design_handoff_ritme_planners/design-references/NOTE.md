# Design references

- `HET RITME Etsy Listings.dc.html` — the approved visual register (desk-studio). Every listing image at
  1000x1000, plus all listing copy in artboard 3d. **This is the source of truth for the Het Ritme look.**
- `Brand System.dc.html` — earlier exploration written under the working name ORDO: logo lockups at
  four scales, both palettes, the same budget screen in both editions, shop assets, and the
  navigation/cell-language spec. The **name is now Het Ritme** and the visual register was superseded by
  the desk-studio direction, but the logo geometry, palettes, nine-screen architecture and cell
  language in this file are all still current.
- `support.js` — runtime needed for the two HTML files to open. Keep it beside them.

Open either file in a browser. Both are pan/zoom canvases — they are wider than a screen by design.
